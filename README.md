# Bhandari Classes – Interactive Tuition LMS Demo

A responsive, front-end prototype for a single-teacher mathematics and quantitative aptitude learning platform.

## Run locally

1. Extract the ZIP.
2. Open `index.html` in Chrome or Edge.
3. No installation or build tools are required.

## Demo walkthrough

- Public website: Home, course catalogue, course filters and contact section.
- Student area: Use `Student Login` to open the sample learner dashboard.
- Demo enrolment: Open a course and select the simulated successful payment option. No money is charged.
- Teacher control panel: Use `Sir's Dashboard` to manage sample courses, lessons, quizzes, daily questions and live-class schedules.
- No-code website editor: Update the home headline and contact details, save, then preview the public page.
- Browser persistence: Demo changes are saved in localStorage in the same browser.

## Important

This is a front-end demonstration only. It does not include production authentication, a backend, database, real Razorpay payments, real video uploads, DRM, or live streaming. These integrations require production implementation and provider accounts. The browser cannot guarantee screenshot or recording prevention.

Contact details and course pricing are sample placeholders and must be confirmed by Bhandari Classes before launch.
